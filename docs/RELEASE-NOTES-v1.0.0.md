# v1.0.0 — Trusted Multi-Agent AI Advisory for Vegetable Oil Refining

First public release. Reference architecture and working implementation of a zero-trust, multi-agent AI advisory system for a vegetable oil refining train, with compliance evidence generated by CI.

## What ships

### Architecture
- Five-layer integrated architecture (process to enterprise governance)
- IEC 62443 zones and conduits as machine-readable YAML
- Purdue / ISA-95 mapping
- Explicit safety boundary (IEC 61511), AI excluded from the SIF

### Digital twin
- Four units: degumming, neutralization, bleaching, deodorization
- Published performance baselines referenced

### Agents
- Quality agent (targets 95% of spec)
- Energy agent (refuses to optimize when off-spec)
- Maintenance agent (RUL on filter sleeves)
- Orchestrator (rank, bounds-check, attest, sign)
- Compliance agent (evidence records per advisory)

### Zero-trust cryptographic plane
- Ed25519 signing with per-agent keypairs
- Eight-stage fail-closed verifier
- Model-version allowlist as OPA-style policy
- Nonce store with post-signature recording

### Zero-trust network plane
- Zone router enforcing IEC 62443 conduit rules
- Reference Containerlab topology (not run in CI)

### Compliance
- ISO/IEC 42001 control-to-evidence matrix
- NIST AI RMF function mapping
- IEC 62443 SL justification
- Evidence pipeline enforcing matrix completeness and model allowlist

### Documentation
- Executive summary, architecture, safety boundary
- What is simulated vs real
- Attack matrix
- Demo script, portfolio notes

## What this is not

Not deployed in a live refinery. Process is a digital twin. HSM is a software stub. Safety layer is a boundary. See docs/WHAT-IS-SIMULATED.md.

## Standards

IEC 62443, IEC 61511, NIST SP 800-82r4 (draft), NIST SP 800-207, ISO/IEC 42001:2023, NIST AI RMF 1.0.
